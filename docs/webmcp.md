# Web MCP 연결

원격제어의 MCP 연결은 HTTPS와 OAuth를 사용합니다. 별도의 로컬 연결기 설치 없이 ChatGPT·Claude·Codex에 https://주소/mcp 를 등록하고 원격제어 ID/비밀번호로 로그인합니다.

## 설정

1. 원격제어 ID와 비밀번호, 잠금 화면 제어 서비스를 설정합니다.
2. **Web MCP 설정 → 웹 HTTPS 연결 설정**에서 직접 입력 주소, Tailscale 또는 프라이빗 터널 연결을 적용합니다. 성공하면 Web MCP 사용이 함께 켜집니다.
3. **Web MCP 주소 복사**로 주소를 등록합니다. 내부망은 **내부망 HTTPS 설정**에서 LAN IP와 공개 CA를 사용합니다.
4. 프로그램을 다시 실행하면 저장된 사용 설정에 따라 Web MCP를 시작합니다. 화면 준비·화면 포트 오류 때문에 MCP 시작이 누락되지 않습니다. 중지된 기존 웹 중계 작업/HTTPS 서비스도 확인합니다.

MCP 사용을 끄면 파일·명령 요청을 처리하지 않습니다. 작업공간은 기본 실행 위치이며 접근 제한 목록이 아닙니다. 파일 작업은 원격 Windows 계정의 권한을 따릅니다.

## 이전 연결 전환

직접 LAN TCP 포트, stdio 연결기, MCPB 확장 대신 HTTPS /mcp 주소를 등록합니다. 기존 Web MCP 주소와 OAuth 인증, 원격제어 설정은 보존됩니다. 기존 로컬 연결기 등록은 사용 중인 클라이언트에서 제거할 수 있습니다. 프로그램은 다른 앱의 등록 설정을 임의로 변경하지 않습니다.

설치 파일은 **dist/RemoteControl_Setup.exe**이며 웹 연결 파일은 **dist/RemoteControl_WebPlugin.zip**입니다. Web MCP가 실제로 열리려면 저장한 HTTPS/터널 설정이 정상이어야 합니다. 웹 연결이 아직 설정되지 않은 PC는 연결 설정을 한 번 적용해야 합니다.


## 브릿지 하위 PC

메인과 하위 PC를 브릿지 MCP 지원 빌드로 업데이트하고 양쪽에서 Web MCP 사용을 켜면, 메인의 기존 HTTPS/OAuth 연결로 하위 PC의 파일·명령·화면 도구를 호출할 수 있습니다. 하위 PC에는 별도 공개 MCP 주소를 만들지 않습니다. [브릿지 MCP 사용법](mcp-bridge-197.md).
