# 다중 파일·폴더 올리기 — v1.6.2

원격 화면의 **파일**을 열고, 받을 PC의 저장할 폴더로 들어간 뒤 다음 방법을 사용합니다.

- **파일 올리기**: 파일 선택 창에서 Ctrl/Shift로 여러 파일을 선택합니다.
- **폴더 올리기**: 폴더를 선택하면 폴더 이름과 내부 하위 경로를 유지해 전송합니다.
- **끌어 놓기**: 파일과 폴더 여러 개를 함께 파일 창에 놓습니다. 이 방법은 빈 폴더도 보존합니다. 폴더 선택 창은 브라우저 특성상 빈 폴더 정보를 제공하지 않습니다.

총 파일 수·전송량·현재 경로가 표시됩니다. 취소하면 남은 전송을 중단하며 이미 완료된 파일은 유지합니다. 실패한 항목은 펼쳐 확인할 수 있고, 연결이 끊겨도 같은 파일을 자동으로 재전송하지 않습니다. 한 번에 파일과 폴더 합계 50,000개까지 받습니다.

같은 이름의 폴더는 기존 폴더에 내용을 추가합니다. 같은 이름의 **파일은 덮어쓰지 않고** `이름 (2).확장자`처럼 비켜 저장합니다. Windows에서 사용할 수 없는 하위 폴더 이름과 연결된 폴더(junction/symlink)는 오류로 표시합니다.

전송 중 폴더 목록을 이동해도 저장 대상은 바뀌지 않습니다. 다른 PC로 전환하면 현재 전송을 취소합니다. 하위 PC로 폴더를 올리려면 해당 PC도 v1.6.2 이상이어야 합니다. 구버전에서는 파일이 한 폴더에 섞이지 않도록 전송을 거절합니다.

폴더 전체를 ZIP으로 만들거나 메모리에 담지 않습니다. 파일을 각각 multipart HTTP로 스트리밍하며 화면 제어 연결과 분리합니다.

검증: `powershell -NoProfile -ExecutionPolicy Bypass -File bench\Test-Upload.ps1`. 실제 제품 HTTP 처리와 격리된 Edge에서 한글·빈 파일·하위 경로·126개 파일 전송을 확인했습니다. 개발 PC의 loopback HTTP에서 작은 파일 126개 전송은 약 0.94초였습니다. 외부 회선 성능을 나타내는 수치는 아닙니다.
