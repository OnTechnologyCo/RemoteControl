# v1.8.22 설치 및 텔레그램 알림

공유할 설치 파일은 `dist/RemoteControl_Setup.exe`입니다. Inno Setup의 한국어 마법사를 사용하며 창 크기를 조절할 수 있습니다. 설치 대상 폴더, 화면 접속 포트, 서비스·자동 실행·방화벽·바탕화면·가상 모니터 옵션을 선택합니다. 웹/LAN MCP는 설치 후에 설정할 수 있습니다. 기존 `uninstall.exe /web-settings`, `/lan-web-settings`와 제거 등록은 유지됩니다.

## 토큰 입력

**텔레그램 알림 (선택)** 단계의 토큰 칸은 마스킹되어 있습니다. 비워 두면 기존 PC의 토큰을 유지하며, 구버전 상수는 실행 없이 메타데이터에서 이전합니다. 토큰을 입력하면 형식을 검사한 뒤 `C:\ProgramData\RemoteControl\credentials\telegram-token.dpapi`에 PC별 DPAPI로 저장합니다. chat_id도 비워 두면 유지하고, 입력한 경우에만 갱신합니다. 토큰의 실제 Telegram 유효성은 설치 중 네트워크로 확인하거나 메시지를 보내지 않습니다. 설치 후 알림 설정의 시험 발송으로 확인할 수 있습니다.

동일한 토큰은 다시 저장하지 않습니다. 다른 토큰을 명시 입력했을 때만 검증된 임시 파일로 원자적으로 교체합니다. 기존 파일이 손상되었거나 권한이 잘못된 경우 덮어쓰지 않습니다. 다른 토큰을 가진 `REMOTE_CONTROL_TELEGRAM_BOT_TOKEN` 환경 변수가 있으면 충돌을 알려 주고 중단합니다.

토큰을 프로세스 명령줄이나 설치 로그에 넣지 않습니다. Inno와 기존 엔진 사이의 입력은 관리자/SYSTEM만 접근하는 임시 폴더에 잠깐 저장하고 엔진이 읽자마자 삭제합니다. 최종 저장 파일은 관리자/SYSTEM 쓰기, 로컬 Users 읽기 권한을 가지므로 트레이와 SYSTEM 서비스가 함께 사용할 수 있습니다. PC의 로컬 사용자/관리자를 신뢰하는 기존 애플리케이션 모델을 유지하며, 암호화가 로컬 관리자에게서 비밀을 숨기는 수단은 아닙니다.

## 개인 PC 간 이전

사용자가 기존 토큰을 다른 PC로 옮기도록 요청한 경우 `tools/Export-TelegramToken.ps1`은 바탕화면에 다음 두 파일을 만듭니다.

- `원격제어_텔레그램_토큰등록.ps1`: 실제 토큰이 하드코딩된 개인 파일. 공개 배포 금지.
- `Apply-RemoteControl-Telegram.cmd`: 같은 폴더의 PS1을 Windows PowerShell로 실행. 실행 결과를 확인할 때까지 창을 유지.

두 파일을 대상 PC의 같은 폴더에 복사하고 CMD를 실행합니다. UAC 승인 후 대상 PC의 DPAPI 저장소에 등록하며, 기존의 다른 토큰·chat_id·서비스·포트를 덮어쓰지 않습니다. 실패 내용은 토큰을 제외하고 `%TEMP%\RemoteControl-Telegram-Import.log`에 기록합니다. CMD와 승격된 PowerShell은 해당 실행에만 `RemoteSigned`를 사용합니다. 조직의 그룹 정책이나 다운로드한 파일의 서명 요구는 무력화하지 않습니다. 생성한 PS1은 소스 저장소·공개 릴리스에 포함하지 않습니다.

## 개발 및 검증

`빌드_setup.ps1`은 현재 본체·MCP 패키지·기존 설치 엔진을 먼저 만들고 Inno Setup 6의 `ISCC.exe`로 최종 설치 파일을 만듭니다. 기본 빌드는 모든 개인 preset을 제외합니다. `dist/RemoteControl.build.json`은 엔진 내장 패키지 해시와 최종 Inno 설치 파일 해시를 기록합니다.

`bench/Test-TelegramSetup.ps1`은 운영 자격 증명과 분리된 가짜 토큰으로 검사합니다. 파일 저장의 암호화 왕복·원자적 교체·권한 거부, 입력 검증, 빈 입력과 마스킹을 포함합니다. `Test-SetupLayout.ps1`은 기존 엔진의 설정/제거 창을 검사하며 Inno 화면 검증과는 별개입니다. 실서비스 설치·제거 및 다른 PC의 관리자 권한 저장은 별도 설치 검증이 필요합니다.
